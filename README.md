# 東京獨旅手札 2026

2026 年 11 月東京獨旅行程的沉浸式翻頁手札，從田端出發，串連神宮外苑、青山表參道、根津美術館、澀谷、麻布台與六本木，並銜接 MSC Bellissima 郵輪行程。

## 功能

- 電影感全幅實景照片與 3D 紙張翻頁
- 桌機、手機、鍵盤與觸控滑動操作
- 每日章節、時間與地圖捷徑
- SHIBUYA SKY、teamLab、根津美術館、21_21 DESIGN SIGHT 搶票順序
- 可勾選的行前清單（儲存在瀏覽器）
- 自動儲存的旅行筆記
- 保留最後閱讀頁面，並支援減少動態效果偏好

## 部署

此網站為純靜態頁面，透過 GitHub Pages 從 `main` branch 根目錄發布。
